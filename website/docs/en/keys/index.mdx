# Keyboard reference

<div className="ld-lede">
Bindings are grouped by tier rather than alphabetically, because that is how they are learned. <Keys>?</Keys> shows the same list inside the application.

Keys are fixed. Every action below has one binding, in every view, on every platform.

## The four tiers

| Tier | Contains | Where you find it |
| --- | --- | --- |
| **L0 universal** | <Keys>↑</Keys> <Keys>↓</Keys> <Keys>←</Keys> <Keys>→</Keys> <Keys>Enter</Keys> <Keys>Esc</Keys> <Keys>q</Keys> <Keys>?</Keys> | The footer, always |
| **L1 vim** | <Keys>j</Keys> <Keys>k</Keys> <Keys>h</Keys> <Keys>l</Keys> <Keys>g</Keys> <Keys>G</Keys> <Keys>/</Keys> <Keys>n</Keys> <Keys>N</Keys> | The footer and <Keys>?</Keys> |
| **L2 actions** | One mnemonic key per verb | <Keys>?</Keys> and the command palette |
| **L3 power** | Chords | This page |

**L0 and L1 are complete alternatives to each other.** Nobody is locked out for not knowing vim, and nobody who knows vim has to reach for an arrow key.

## Coherence rules

Six rules cover the whole keymap. They are what let you guess a key you have not learned.

1. **Lowercase acts on the row; uppercase escalates or reverses it.** <Keys>x</Keys> closes, <Keys>X</Keys> reopens. <Keys>d</Keys> marks one done, <Keys>D</Keys> marks all. <Keys>r</Keys> refreshes one, <Keys>Ctrl+R</Keys> refreshes all.
2. **A key means the same verb in every view.** <Keys>R</Keys> retries. <Keys>x</Keys> stops. <Keys>m</Keys> makes it go: merge a merge request, or play a manual job. <Keys>L</Keys> shows logs. <Keys>w</Keys> keeps showing you a live thing, a running pipeline or a growing log. <Keys>z</Keys> collapses a Home group, a tree node, or a log section.
3. **A key resolves to one action in the context you are in.** Nothing is bound twice in the same view, so what you learned in one table still holds in the next.
4. **<Keys>n</Keys> and <Keys>N</Keys> are search navigation only**, and only while a search is live. That is why "new merge request" is <Keys>Ctrl+N</Keys>.
5. **<Keys>Esc</Keys> never quits, <Keys>q</Keys> never goes back.** <Keys>Esc</Keys> moves back exactly one level, and it will not discard a half-typed comment without asking.
6. **No timed key sequences.** A chord is `Ctrl`-prefixed and instantaneous. A `g`-then-`g` with a timeout produces mystery input on a slow SSH link.
